{% hint style="info" %}
Кожен сенсор має два автоматично згенерованих сенсори для мінімальних і максимальних значень. Вони мають однакову назву з додаванням символів мінуса або плюса в кінці. Наприклад: **RXBt +**. Це відображає максимальне значення, яке сенсор досягнув під час польоту. Використовуйте  [Reset Telemetry](../../main-view/reset.md)[ ](../../main-view/reset.md)або функцію **Flight** щоб скинути це значення до 0.
{% endhint %}
