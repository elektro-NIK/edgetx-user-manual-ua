{% hint style="info" %}
Кожен датчик має два автоматично згенеровані датчики для їхніх мінімальних і максимальних значень. Вони мають однакові назви з символами плюс та мінус, доданими в кінці. Наприклад: RXBt + відображає максимальне значення, яке датчик досяг під час польоту. Використання функції [Скидання телеметрії](../../reset-telemetry.md) або Скидання польоту скине це значення до 0.
{% endhint %}
