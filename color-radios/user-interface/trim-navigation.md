# Навігація тримерами

На апаратурах NV14 і EL18 можна переміщатися по параметрах меню за допомогою тримерів.

На екрані налаштування апаратури ви можете налаштувати режим тримерів за допомогою одного з таких параметрів:

<div data-full-width="true"><figure><img src="../../.gitbook/assets/hat3.png" alt=""><figcaption><p>Опція режиму тримерів</p></figcaption></figure> <figure><img src="../../.gitbook/assets/hat4.png" alt=""><figcaption><p>Варіанти конфігурації</p></figcaption></figure> <figure><img src="../../.gitbook/assets/hat 5 (1).png" alt=""><figcaption><p>Підказка до режиму тримерів</p></figcaption></figure></div>

* **Trims** **only**: The Trim hat switches will be used to adjust the trim values only.
* **Keys only**: The Trim hat switches will be used to navigate the menu options (as described below)
* **Switchable**: Trim hat switch functionality can be changed between **Trims** and **Keys** on-the-fly.

<div><figure><img src="../../.gitbook/assets/hat1 (1).png" alt=""><figcaption><p>Keys mode</p></figcaption></figure> <figure><img src="../../.gitbook/assets/hat2.png" alt=""><figcaption><p>Trims mode</p></figcaption></figure></div>

### To switch between modes on-the-fly

1. Configure **Hats Mode** as **Switchable**.
2. Press and hold the **Left Hat.**
3. Immediately after, press the **Right Hat**.

{% hint style="info" %}
When the radio is powered up and Hats Mode is set to **Switchable**, the initial mode will always be set to **Trims**.
{% endhint %}
